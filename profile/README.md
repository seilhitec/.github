## 🏢 About Us

We are the **Touch Solution (TS) Development Team** at **Seilhitec**.
We build PCT touch controllers end to end — hardware, firmware, and PC tools.

## 🔧 What We Do

| Area | Focus |
|:--|:--|
| 🔌 **Hardware** | Touch controller boards, sensor interface, EMC-robust design |
| 💾 **Firmware** | MCU firmware in C (GCC), USB HID / I²C interfaces |
| 🖥️ **Software** | Tuning, calibration and test tools |
| ✅ **Quality** | Test jigs, verification, mass-production support |
